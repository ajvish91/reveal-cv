# CV sidebar icons

Contact icons are from [Lucide](https://lucide.dev/) (ISC license), fetched via the Iconify API.

| File | Lucide icon |
|------|-------------|
| `phone.png` | `phone` |
| `email.png` | `mail` |
| `location.png` | `map-pin` |
| `github.png` | `github` |
| `linkedin.png` | `linkedin` |
| `google_scholar.png` | `lucide:graduation-cap` |
| `orcid.png` | `lucide:id-card` |
| `cake.png` | `cake` (date of birth) |

Source SVGs are kept alongside PNGs for regeneration:

```bash
.venv/bin/python -m pip install cairosvg
# Re-download and render (color matches sidebar text #eef2f7)
```
