Inspirit er Skandinavias ledende fagmiljø innen Microsofts forretningsløsninger, og Data Platform-teamet er en integrert del av de fleste kundeleveransene vi gjør. Nå styrker vi teamet med to roller: en senior data engineer og vår første dedikerte data scientist. Hos oss tror vi på å bygge kompetansen på huset. Teamet møtes ukentlig for å sparre, dele og lære av hverandre, og det er slik vi sikrer at fagmiljøet vokser i takt med at kundenes behov blir mer komplekse. Målet er det samme uansett hvilken rolle du søker: at data faktisk betyr noe for kundene våre. Data Engineer Som data engineer designer, utvikler og forvalter du moderne dataplattformer for våre kunder, med Microsoft-teknologi i kjernen. Du sørger for at data flyter jevnt, transformeres korrekt og gjøres tilgjengelig for innsikt, rapportering og AI. Ansvarsområder Designe og bygge dataplattformer i Azure, inkludert Microsoft Fabric, Synapse, Data Lake og Data Factory Utvikle datamodeller og transformasjoner med dbt, Python, PySpark og SQL, og strukturere pipelines med høy gjenbrukbarhet og ytelse Modellere og dokumentere semantiske lag og datamodeller (star/snowflake, medallion) Utvikle og optimalisere integrasjoner (GraphQL, REST, Docker, Python) mellom dataplattform og forretningssystemer Bidra til etablering og vedlikehold av robuste CI/CD-pipelines, DevOps-praksiser og infrastructure as code med Terraform Jobbe tett med BI-utviklere og løsningsarkitekter for å sikre helhetlige leveranser Data Scientist Som vår første dedikerte data scientist tar du datagrunnlaget som teamet tilgjengeliggjør og gjør det om til innsikt og modeller som faktisk brukes. Du stiller de riktige spørsmålene, bygger modeller som holder i produksjon, og omsetter funnene til noe kunden kan handle på. Fordi teamet er lite, jobber du i skjæringspunktet mellom modellering og plattform. Du trenger ikke å gå dypt ned i infrastrukturen, men du bør kjenne til den. Ansvarsområder Bygge, trene og sette prediktive modeller og ML-løsninger i produksjon på kundedata Jobbe med Fabric Notebooks og Azure ML som primære plattformer Samarbeide med data engineers om datakvalitet, feature engineering og dataflyt Oversette forretningsproblemer til analytiske tilnærminger i tett dialog med kunder Kommunisere funn og modellinnsikt på en måte som gir beslutningsgrunnlag Bidra til å definere og bygge Inspirits data science-praksis over tid Hvem ser vi etter?
